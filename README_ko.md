# Rotaeno 레이팅 계산 로직

이 코드는 Rotaeno에서 플레이어의 레이팅을 계산하는 로직을 구현합니다. **2.8.41**버전 기준의 로직을 따릅니다.

## 용어

더 나은 이해를 위하여 몇몇 용어를 정의합니다. 일부 용어는 통용적으로 사용되는 의미와 다를 수 있습니다.

- **차트**: 각 곡의 난이도마다 유일하게 존재하는 것으로, 점수를 포함한 플레이 결과를 저장하는 오브젝트입니다.
- **곡**: 하나의 곡을 의미합니다. 난이도 별로 차트를 가집니다.
- **점수**: 플레이를 통해 얻은 점수값입니다.
- **레이팅**: 아래와 같이 크게 2가지의 의미를 가집니다.
  - **차트 레이팅** 또는 **개별 레이팅**은 각 차트 별로 점수와 난이도에 따라 결정되는 값입니다.
  - **총 레이팅** 또는 **레이팅**은 공식에 따라 개별 레이팅 값을 합산하여 결정되는 값입니다.
- **난이도**: 각 차트의 난이도가 표시 문자열입니다. `I`, `II`, `III`, `IV`, `IV-α`의 5가지 값 중 하나입니다.
- **난이도 상수**: 각 차트의 난이도를 정량적으로 나타내는 소수값입니다. 예시로, 가장 높은 난이도 상수는 翠杜의 **14.5**입니다.
- **점수 보너스**, **보너스**: 개별 레이팅을 계산할 때 사용되는 값으로, 점수에 따라 최종 값에 추가됩니다.

## 개별 레이팅 계산

Rotaeno에서는 점수 구간에 따라 아래와 같이 티어를 나누고 보너스 값을 제공합니다:

|      점수 구간      |   보너스 구간    | 기울기(1e-6) |
| :-----------------: | :--------------: | :----------: |
|      `1010000`      |      `+3.7`      |              |
| `1008000`~`1009999` |  `+3.4`~`+3.6`   |    100.05    |
| `1004000`~`1008000` |  `+2.4`~`+3.4`   |   **250**    |
| `1000000`~`1004000` |  `+2.0`~`+2.4`   |     100      |
| ` 980000`~`1000000` |  `+1.0`~`+2.0`   |      50      |
| ` 950000`~` 980000` |  `±0.0`~`+1.0`   |    33.33     |
| ` 900000`~` 950000` |  `-1.0`~`±0.0`   |      20      |
| ` 800000`~` 900000` |  `-2.0`~`-1.0`   |      10      |
| ` 700000`~` 800000` |  `-3.0`~`-2.0`   |      10      |
| ` 600000`~` 700000` |  `-4.0`~`-3.0`   |      10      |
| ` 500000`~` 600000` |  `-5.0`~`-4.0`   |      10      |
| `      0`~` 500000` | `-9999.0`~`-5.0` |    19988     |

위 티어에 따라, 개별 레이팅 값은 아래와 같이 계산됩니다:

- 이론치(`1010000`)인 경우
  $$(난이도\ 상수)+3.7$$
- 점수 $s$에 대하여 점수 구간 $s_1,s_2$ 사이에 존재할 때, 주어지는 보너스가 $b_1,b_2$라고 한다면
  $$(난이도\ 상수)+b_1+(b_2-b_1)\times\frac{s-s_1}{s_2-s_1}$$

이렇게 계산된 개별 레이팅 값에서 아래와 같이 후처리 과정이 진행됩니다:

- 만약 계산된 값이 음수라면, 0으로 간주합니다.
- 만약 해당 차트가 클리어하지 못한 차트라면, 최대 6.0의 값을 가질 수 있습니다.

## 총 레이팅 계산

위에서 계산한 개별 레이팅 값을 기준으로, 총 레이팅은 아래와 같은 로직으로 계산됩니다:

1. 모든 곡의 차트 정보를 불러옵니다.
1. 아래와 같은 규칙에 따라 곡 별로 차트를 골라냅니다.
   - `I`, `II`, `III`의 난이도는 모두 포함합니다.
   - `IV` 난이도와 `IV-α` 난이도가 모두 존재한다면, 더 높은 개별 레이팅 값을 가지는 차트를 포함합니다.
1. 이렇게 모은 차트를 개별 레이팅이 높은 순으로 정렬합니다.
1. 앞에서부터 40개의 차트를 골라 아래의 계산식을 적용합니다($c_i$는 $i$번째 차트의 개별 레이팅):
   $$
   \frac{c_1+...+c_{10}}{10}\times0.6+\frac{c_{11}+...+c_{20}}{10}\times0.2+\frac{c_{21}+...+c_{40}}{20}\times0.2
   $$
1. 이렇게 계산한 값에서 소수점 3자리를 남기고 나머지는 버립니다.
